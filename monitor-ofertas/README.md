# Monitor de Ofertas Mejorado

Cambios aplicados:

- Descuentos detectados desde 60% hasta 99%
- Clasificación de ofertas:
  - 🔥 ERROR PRECIO (90%+)
  - 🚨 OFERTA EXTREMA (80-89%)
  - 🔥 BUENA OFERTA (60-79%)
- Keywords ampliadas para tecnología, gaming, hogar y moda
- Preparado para integrar Liverpool, Amazon y otras tiendas
- Mantiene historial con vistos.json para evitar repetir ofertas
